static load_from_tiff(file_path: Path, band: int = 1, bounding_box: BoundingBox | None = None) → RasterNp

Build a RasterNp object from a tiff file.

This may work with other geo-image types, too, but is untested.

Parameters:

  • file_path (Path) – The file path to attempt to load.

  • band (int) – Which raster band to load, by default 1 (the first one)

  • bounding_box (BoundingBox | None) – If a bounding box is passed, only a sub-area of the tiff is loaded. If the bounding box bounds are greater than the image bounds, they are trimmed down to the image bounds. All partial pixels touched by the bounding box are returned. If None, the entire tiff is loaded. By default None.

Returns:

New RasterNp instance.

Return type:

RasterNp

Raises:

ValueError – If requested extent does not overlap the file extent.
