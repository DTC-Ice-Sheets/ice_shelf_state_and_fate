iceshelf_polygon(ice_shelf_polygons: GeoDataFrame, ice_shelf_name: str) → tuple[Polygon | MultiPolygon, Polygon | MultiPolygon]

Extract the ice shelf multipolygon for an ice shelf in both EPSG4326(lat/lon) and the input projection.

Parameters:

  • ice_shelf_polygons (gpd.GeoDataFrame) – Input GeoDataFrame with atleas the column ‘Name’ for the ice shelf name and ‘geometry’ with the polygon. This GeoDataFrame must have a valid CRS.

  • ice_shelf_name (str) – The ice shelf name

Returns:

The shapely object for the specified ice shelf in both EPSG4326(lat/lon) and the input projection.

Return type:

tuple[Polygon | MultiPolygon, Polygon | MultiPolygon]

ocean_polygon(ice_shelf_polygons: GeoDataFrame, ice_shelf_name: str, distance: int | float = 10000) → tuple[Polygon | MultiPolygon, Polygon | MultiPolygon]

Extract the ice shelf ocean multipolygon for an ice shelf in both EPSG4326(lat/lon) and the input projection. To do this a buffer of ‘distance’ units is applied to the ice shelf polygon.

Parameters:

  • ice_shelf_polygons (gpd.GeoDataFrame) – Input GeoDataFrame with atleas the column ‘Name’ for the ice shelf name and ‘geometry’ with the polygon. This GeoDataFrame must have a valid CRS.

  • ice_shelf_name (str) – The ice shelf name

  • distance (int | float) – The distance in projected units to buffer the ice shelf polygon, by default 10000

Returns:

The shapely object for the ocean around the specified ice shelf in both EPSG4326(lat/lon) and the input projection.

Return type:

tuple[Polygon | MultiPolygon, Polygon | MultiPolygon]
