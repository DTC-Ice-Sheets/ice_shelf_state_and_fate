class TimeSeriesPreprocessor(timeseries: list[Timeseries], time_period: AggregationPeriod | None = None, aggregation: AggregationStrategy = AggregationStrategy.MEAN, process_timeseries: bool = True)

Bases: object

Module for the manipulation of timeseries.

Parameters:

  • timeseries (list[Timeseries]) – The list of timeseries objects.

  • time_period (AggregationPeriod | None) – The aggregation period to apply. If None, the coarsest frequency from the input timeseries is used.

  • aggregation (AggregationStrategy) – The aggregation type to apply, by default AggregationStrategy.MEAN

  • process_timeseries (bool) – Whether to preprocess all of the input timeseries, by default True

find_start_end_dates() → tuple[Timestamp | datetime64 | int, Timestamp | datetime64 | int]

Return the greatest common start and the smallest common end time for a set of time series.

If both input parameters are None then it will check all of the timeseries in the container.

Returns:

The start and end datetime. Note it is possible for the end time to be less than the start time in cases where the time series do not intersect in time

Return type:

tuple[Timestamp, Timestamp]

process_timeseries() → None

Process the timeseries for the covariate analysis.

This first checks that all the timeseries intersect in time, it then resamples the timeseries to be the same frequency, trims the time series to be the same length and then interpolates any missing values using linear interpolation.

trim_start_end_dates(start_date: Timestamp | datetime64 | int, end_date: Timestamp | datetime64 | int) → None

Trim a time series using a start and end date time.

Parameters:

  • start_date (Timestamp) – The start date to trim.

  • end_date (Timestamp) – The end date to trim.
