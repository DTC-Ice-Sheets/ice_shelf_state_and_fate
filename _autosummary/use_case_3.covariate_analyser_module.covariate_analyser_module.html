static fit_power_law_nonlinear(x: ndarray, y: ndarray, alpha: float = 0.05) → dict

Fit a nonlinear power-law model and estimate confidence intervals.

Fit the model y = a * x**b using several initial estimates for the exponent, then select the fit with the lowest residual sum of squares.

Parameters:

  • x (np.ndarray) – Provide the independent variable values.

  • y (np.ndarray) – Provide the dependent variable values.

  • alpha (float) – Set the significance level used to calculate confidence intervals for the model parameters.

Returns:

Return the fitted parameters a and b, their confidence intervals, residual sum of squares (rss), coefficient of determination (r2), and sample count (n).

Return type:

dict

Raises:

  • ValueError – Raise when any x value is negative or there are not more than two data points.

  • RuntimeError – Raise when the fit fails for every initial exponent estimate.
