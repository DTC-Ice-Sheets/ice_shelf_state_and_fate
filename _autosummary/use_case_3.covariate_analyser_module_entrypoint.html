Plot covariate analysis from a set of pre-processed timeseries.

Parameters:

  • input_path (ZarrType) – Path to the input .zarr store containing pre-processed timeseries. Can be a local path or web URL.

  • output_path (Path) – Path to save the output .json file.

  • analysis_type (JointPlotAnalysisType) – Type of covariate analysis to perform.
