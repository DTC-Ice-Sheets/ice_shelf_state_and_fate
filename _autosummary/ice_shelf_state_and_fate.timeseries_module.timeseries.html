process_timeseries(data: Dataset, measurement_name: str, measurement_uncertainty_name: str | None, mask_geometry: Polygon | MultiPolygon | None, apply_mask: bool, aggregate: AggregationStrategy = AggregationStrategy.MEAN, period: AggregationPeriod | None = AggregationPeriod.MONTH, uncertainty: UncertaintyType | None = None, independent: bool = False, t0_normalisation: str | None = None) → None

Process the input data into a timeseries with associated uncertainties and coverage.

This is the main method processing the datacube into the time series. This works with both 3D and 1D data.

NOTE: Main entry point. NOTE: This function has been split into two separate functions depending on the data dimensionality. This is in attempt to simplify and make things more readable.

Parameters:

  • data (xr.Dataset) – The xarray dataset containing the measurement of interest as well as any other data of interest such as uncertainties. Ideally, this should be an xr.Dataset which has been read from an appropriately formatted GeoZarr.

  • measurement_name (str) – The specific measurement to be processed. This must be a key of a DataArray with the data xr.Dataset.

  • measurement_uncertainty_name (str | None) – The specific name of the uncertainty associated with the measurement. If None, it is assumed that the measurement will have no associated uncertainty.

  • mask_geometry (Polygon | MultiPolygon | None) – The mask geometry

  • apply_mask (bool) – Boolean flag whereby if True the mask supplied to the data will be used to mask the data. If False then the mask is only used to calculate the coverage.

  • aggregate (AggregationStrategy) –

    The aggregation to perform on the data, by default AggregationStrategy.MEAN. Currently these are limited to: mean, median, max, min. Note, the aggregation chosen determines the spread according to the following rules:

    • mean: standard deviation

    • median: IQR

    • max/min: None

  • period (AggregationPeriod | None) – The time period over which to aggregate, by default AggregationPeriod.MONTH

  • uncertainty (UncertaintyType | None) – The statistic type describing the uncertainty, by default None

  • independent (bool) – Whether the uncertainties are independent or not, by default False

  • t0_normalisation (str | None) – Whether to normalise the time series against time zero, by default None
