# DTC-IS Super Resolution Module

The `ice_shelf_state_and_fate` module is a sub-component of the
[Digital Twin Component for Ice Sheets (DTC-IS)](https://dtc-ice-sheets.org/), an ESA-funded, EO-driven digital twin project.

This software package leverages super-resolution modeling techniques to enhance the monitoring and prediction of surface climate conditions over Greenland and Antarctica.

For an in-depth overview of the ice_shelf_state_and_fate module please [read the docs](https://dtc-ice-sheets.github.io/ice_shelf_state_and_fate/).

The documentation includes sections on:

1. [Getting started](https://dtc-ice-sheets.github.io/ice_shelf_state_and_fate/quick-start.html)
1. [Scientific overview](https://dtc-ice-sheets.github.io/ice_shelf_state_and_fate/overview.html)
1. [API reference](https://dtc-ice-sheets.github.io/ice_shelf_state_and_fate/api.html)

For a more interactive way of exploring the system, please visit the digital twin's [dashboard](https://dashboards.dtc-ice-sheets.org/).

## Installation for Use

You can install this package with pip:

``` bash
pip install ice_shelf_state_and_fate
```
